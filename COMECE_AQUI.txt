📌 PASSO 1: Instale as Dependências
─────────────────────────────────────────────────────────────────────────────

No terminal, execute:
    npm install

Isso vai instalar todas as bibliotecas necessárias.


📌 PASSO 2: Obtenha seu Token Telegram
─────────────────────────────────────────────────────────────────────────────

1. Abra o Telegram e procure por: @BotFather
2. Digite: /newbot
3. Dê um nome ao seu bot (ex: MeuBot)
4. Dê um username único (ex: meu_bot_123456)
5. Copie o token gerado (será algo como: 123456:ABCD...)


📌 PASSO 3: Configure o Token
─────────────────────────────────────────────────────────────────────────────

1. Abra o arquivo: index.js
2. Procure pela linha: const token = 'SUBSTITUA_PELO_SEU_TOKEN';
3. Substitua 'SUBSTITUA_PELO_SEU_TOKEN' pelo seu token
4. Salve o arquivo (Ctrl+S)


📌 PASSO 4: Inicie o Bot
─────────────────────────────────────────────────────────────────────────────

No terminal, execute:
    node index.js

Você deve ver:
    ✅ Bot conectado e pronto para usar!


📌 PASSO 5: Teste seu Bot
─────────────────────────────────────────────────────────────────────────────

1. No Telegram, procure pelo @username que você criou
2. Clique em INICIAR
3. Digite: /start
4. Clique em um dos botões
5. Sucesso! Seu bot está funcionando! 🎉

❓ PROBLEMAS?

❌ "Cannot find module"
✅ Execute: npm install

❌ Bot não responde
✅ Verifique se:
   • O token está correto
   • Internet está conectada
   • Reinicie o bot (Ctrl+C e node index.js novamente)

❌ Mensagem de erro no terminal
✅ Leia o erro e procure na seção "Troubleshooting" do leia-me.txt
