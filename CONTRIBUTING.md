# Como Contribuir

Obrigado por considerar contribuir para este projeto! 🎉

## Passos para Contribuir

### 1. Fork o Repositório
Clique no botão "Fork" no GitHub para criar sua cópia.

### 2. Clone seu Fork
```bash
git clone https://github.com/seu-usuario/telegram-bot-base.git
cd telegram-bot-base
```

### 3. Crie uma Branch para sua Feature
```bash
git checkout -b feature/minha-feature
```

### 4. Faça suas Mudanças
- Adicione novos comandos em `comandos/`
- Atualize a documentação se necessário
- Mantenha o código limpo e bem comentado

### 5. Commit suas Mudanças
```bash
git commit -m "Adiciona feature X"
```

### 6. Push para sua Branch
```bash
git push origin feature/minha-feature
```

### 7. Abra um Pull Request
No GitHub, abra um PR descrevendo suas mudanças.

## Diretrizes

- ✅ Mantenha o código limpo e bem organizado
- ✅ Adicione comentários em código complexo
- ✅ Teste antes de submeter
- ✅ Atualize a documentação se necessário
- ✅ Use nomes descritivos para branches e commits

## Reportar Bugs

Abra uma Issue descrevendo:
- O que aconteceu
- O que deveria acontecer
- Como reproduzir
- Versão do Node.js
- Sistema operacional

## Sugestões e Melhorias

Sinta-se livre para sugerir melhorias abrindo uma Issue!
