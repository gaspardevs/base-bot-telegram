🎯 OBJETIVO DESTE TUTORIAL:
Criar um comando chamado /clima que simula uma busca de clima e retorna
a temperatura atual de uma cidade.

⏱️ Tempo estimado: 5 minutos


╔════════════════════════════════════════════════════════════════════════════╗
║ PASSO 1: ENTENDER O FLUXO                                                  ║
╚════════════════════════════════════════════════════════════════════════════╝

Vamos visualizar o que acontece quando você clica no botão:

╔════════════════════════════════════════════════════════════════════════════╗
║ PASSO 2: CRIAR O ARQUIVO DO COMANDO                                        ║
╚════════════════════════════════════════════════════════════════════════════╝

1. Abra a pasta "comandos"
2. Clique direito → Novo Arquivo
3. Nomeie como: clima.js
4. Cole o código abaixo:

┌────────────────────────────────────────────────────────────────────────────┐
│ async function clima(bot, chatId) {                                        │
│     const temperaturas = {                                                 │
│         'São Paulo': '28°C',                                               │
│         'Rio de Janeiro': '30°C',                                           │
│         'Brasília': '25°C',                                                │
│         'Salvador': '32°C',                                                │
│         'Curitiba': '20°C'                                                 │
│     };                                                                     │
│                                                                            │
│     const cidades = Object.keys(temperaturas);                             │
│     const cidade = cidades[Math.floor(Math.random() * cidades.length)];   │
│     const temp = temperaturas[cidade];                                    │
│                                                                            │
│     const mensagem = `                                                     │
│ 🌡️ CLIMA ATUAL                                                             │
│                                                                            │
│ Cidade: ${cidade}                                                         │
│ Temperatura: ${temp}                                                      │
│ Condição: ☀️ Ensolarado                                                   │
│ Umidade: 65%                                                              │
│     `.trim();                                                             │
│                                                                            │
│     await bot.sendMessage(chatId, mensagem);                              │
│ }                                                                          │
│                                                                            │
│ module.exports = { clima };                                               │
└────────────────────────────────────────────────────────────────────────────┘

📌 O que cada parte faz:

• async function clima() = Define a função de forma assíncrona (para operações
  que demoram)

• const temperaturas = {...} = Simula um banco de dados com temperaturas

• Math.random() = Escolhe uma cidade aleatória

• bot.sendMessage() = Envia a mensagem pro usuário

• module.exports = { clima } = Exporta para ser usada em outro arquivo


╔════════════════════════════════════════════════════════════════════════════╗
║ PASSO 3: IMPORTAR O COMANDO NO INDEX.JS                                    ║
╚════════════════════════════════════════════════════════════════════════════╝

Abra index.js e procure pelas linhas:

┌────────────────────────────────────────────────────────────────────────────┐
│ require('./comandos/ping')(bot);                                           │
│ require('./comandos/menu')(bot);                                           │
│ require('./comandos/relatarbug')(bot);                                     │
└────────────────────────────────────────────────────────────────────────────┘

LOGO APÓS essas linhas, adicione:

┌────────────────────────────────────────────────────────────────────────────┐
│ require('./comandos/clima')(bot);                                          │
└────────────────────────────────────────────────────────────────────────────┘

Depois procure pelas linhas:

┌────────────────────────────────────────────────────────────────────────────┐
│ const { ping } = require('./comandos/ping');                              │
│ const { menu } = require('./comandos/menu');                              │
│ const { relatarBug } = require('./comandos/relatarbug');                  │
└────────────────────────────────────────────────────────────────────────────┘

LOGO APÓS, adicione:

┌────────────────────────────────────────────────────────────────────────────┐
│ const { clima } = require('./comandos/clima');                            │
└────────────────────────────────────────────────────────────────────────────┘


╔════════════════════════════════════════════════════════════════════════════╗
║ PASSO 4: ADICIONAR CALLBACK NO INDEX.JS                                    ║
╚════════════════════════════════════════════════════════════════════════════╝

Abra index.js e procure por:

┌────────────────────────────────────────────────────────────────────────────┐
│ bot.on('callback_query', async (query) => {                               │
│     const chatId = query.message.chat.id;                                 │
│     responderCallback(bot, query.id);                                     │
│                                                                            │
│     if (query.data === 'ping') await ping(bot, chatId);                   │
│     if (query.data === 'menu') menu(bot, chatId);                         │
│     if (query.data === 'info') await info(bot, chatId);                   │
│     ...                                                                    │
│ });                                                                        │
└────────────────────────────────────────────────────────────────────────────┘

Dentro desse bloco, APÓS o último "if", adicione:

┌────────────────────────────────────────────────────────────────────────────┐
│     if (query.data === 'clima') await clima(bot, chatId);                │
└────────────────────────────────────────────────────────────────────────────┘

Resultado esperado:

┌────────────────────────────────────────────────────────────────────────────┐
│ bot.on('callback_query', async (query) => {                               │
│     const chatId = query.message.chat.id;                                 │
│     responderCallback(bot, query.id);                                     │
│                                                                            │
│     if (query.data === 'ping') await ping(bot, chatId);                   │
│     if (query.data === 'menu') menu(bot, chatId);                         │
│     if (query.data === 'info') await info(bot, chatId);                   │
│     ...                                                                    │
│     if (query.data === 'clima') await clima(bot, chatId);    ← NOVA LINHA │
│ });                                                                        │
└────────────────────────────────────────────────────────────────────────────┘

╔════════════════════════════════════════════════════════════════════════════╗
║ PASSO 7: DEBUGAR SE NÃO FUNCIONAR                                          ║
╚════════════════════════════════════════════════════════════════════════════╝

❌ Problema: O botão não aparece
✅ Solução: 
   • Verifique se salvou o arquivo comandos_buttons.js
   • Restart o bot (Ctrl+C e node index.js novamente)

❌ Problema: Clico mas nada acontece
✅ Solução:
   • Verifique se o callback_data no botão é exatamente 'clima'
   • Verifique se adicionou o if (query.data === 'clima') no index.js
   • Procure por erros no terminal

❌ Problema: Aparece erro "Cannot find module"
✅ Solução:
   • Verifique se o arquivo está em ./comandos/clima.js
   • Verifique a grafia do require no index.js

❌ Problema: Aparece erro de syntax
✅ Solução:
   • Verifique se fechou todas as chaves {}
   • Verifique se fechou todas as aspas ""
   • Verifique se usou await e async corretamente
