📋 OS 3 COMANDOS BÁSICOS:
─────────────────────────────────────────────────────────────────────────────

1️⃣ /ping ou botão "📊 Status"
   └─ Mostra:
      • Tempo de resposta (ping)
      • Memória RAM total
      • Memória RAM livre
      • Memória RAM usada
      • Memoria RSS do bot
      • Memória Heap do bot

2️⃣ /menu ou botão "📋 Menu"
   └─ Exibe:
      • Menu principal com opções
      • Botões para todos os 3 comandos
      • Links para canais

3️⃣ /info ou botão "ℹ️ Informações"
   └─ Mostra:
      • Descrição do bot
      • Lista de todos os comandos
      • Como usar o bot
      • Botões de navegação

🔧 PRÓXIMOS PASSOS:
─────────────────────────────────────────────────────────────────────────────

1. Leia COMECE_AQUI.txt para configuração rápida
2. Configure seu TOKEN do @BotFather no index.js
3. Execute: npm install
4. Inicie: node index.js
5. Teste no Telegram: /start

→ Adicionar seus próprios comandos

💡 COMO ADICIONAR NOVOS COMANDOS:
─────────────────────────────────────────────────────────────────────────────

A base está preparada para que você adicione comandos facilmente!

1. Crie um novo arquivo em: comandos/seucomando.js
2. Use os comandos existentes como template
3. Importe no index.js (require + const)
4. Adicione callback no bot.on('callback_query')
5. Crie um botão em comandos_buttons.js
6. Teste!

Veja: TUTORIAL_CRIAR_COMANDO.txt para instruções detalhadas.
