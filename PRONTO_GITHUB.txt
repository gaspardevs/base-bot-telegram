   └─ Marque "Add a README file" (já temos)

2. No terminal, inicialize git local
   └─ cd c:\Users\Aluno\Desktop\base-bot-telegram
   └─ git init
   └─ git add .
   └─ git commit -m "Initial commit: Base bot Telegram"

3. Conecte ao repositório remoto
   └─ git remote add origin https://github.com/seu-usuario/telegram-bot-base.git
