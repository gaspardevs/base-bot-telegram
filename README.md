# 📖 Sobre

**Base Bot Telegram** é uma base desenvolvida em **Node.js**, criada para facilitar o desenvolvimento de bots para Telegram.

O projeto possui uma estrutura organizada, modular e de fácil compreensão, permitindo adicionar novos comandos e funcionalidades rapidamente.

Ideal para quem deseja iniciar um novo projeto sem precisar montar toda a estrutura do zero.

---

# ✨ Recursos

* 📂 Estrutura organizada
* ⚡ Código simples e limpo
* 🤖 Integração com a API do Telegram
* 📦 Sistema modular
* 🛠️ Fácil manutenção
* 🚀 Fácil expansão
* 📁 Separação por arquivos
* 💬 Sistema de comandos

---

# ⚙️ Requisitos

* Node.js 18 ou superior
* npm

---

# 📥 Instalação

Clone o repositório:

```bash
git clone https://github.com/gaspardevs/base-bot-telegram.git
```

Entre na pasta:

```bash
cd base-bot-telegram
```

Instale as dependências:

```bash
npm install
```

---

# 🚀 Iniciando

Execute:

```bash
node index.js
```

ou

```bash
npm start
```

---

# 📂 Organização

| Pasta    | Descrição                    |
| -------- | ---------------------------- |
| comandos | Todos os comandos do bot     |
| eventos  | Eventos do Telegram          |
| config   | Configurações do projeto     |
| database | Banco de dados               |
| assets   | Arquivos utilizados pelo bot |
| src      | Código principal             |
