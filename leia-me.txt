1️⃣ O QUE É ESSA BASE?
─────────────────────────────────────────────────────────────────────────────
Esta é uma base pronta para Bot Telegram desenvolvida em Node.js. Serve como
ponto de partida para criar bots com:

✅ Sistema de botões interativos (inline_keyboard)
✅ Comandos customizáveis (/ping, /play, /menu, etc)
✅ Gerenciamento de callbacks
✅ Download de músicas do YouTube
✅ Sistema de reportagem de bugs e avaliações
✅ Informações do bot (ping, RAM, etc)

Você pode usar esta base como template e adicionar seus próprios comandos e
funcionalidades!


2️⃣ REQUISITOS E INSTALAÇÃO
─────────────────────────────────────────────────────────────────────────────

📌 REQUISITOS:
• Node.js (versão 14+)
• npm (gerenciador de pacotes)
• Um Token de Bot Telegram (criar em @BotFather)

📥 PASSOS DE INSTALAÇÃO:

1. Abra o terminal na pasta do projeto

2. Instale as dependências:
   npm install

3. Configure seu Token:
   • Abra o arquivo index.js
   • Localize a linha: const token = 'AQUI_VAI_SEU_TOKEN';
   • Substitua 'AQUI_VAI_SEU_TOKEN' pelo token fornecido pelo @BotFather

4. Inicie o bot:
   node index.js

4️⃣ CONFIGURAÇÃO INICIAL
─────────────────────────────────────────────────────────────────────────────

🔧 PASSO 1: Obter Token do Telegram

1. Abra o Telegram e procure por @BotFather
2. Digite: /newbot
3. Dê um nome ao bot (ex: MeuBot)
4. Dê um username único (ex: meu_bot_unico)
5. Copie o token fornecido

🔧 PASSO 2: Configurar o Token

Abra o arquivo index.js e procure por:
┌────────────────────────────────────────────┐
│ const token = '8980498014:AAHC6BD...';     │

Substitua pelo seu token.

Abra buttons.js e atualize os links dos seus canais:
┌────────────────────────────────────────────┐

5️⃣ COMO FUNCIONAM OS COMANDOS
─────────────────────────────────────────────────────────────────────────────

🎯 FLUXO DE FUNCIONAMENTO:

1. Usuário digita /start ou clica em um botão
2. O bot responde com mensagem + botões (inline_keyboard)
3. Usuário clica em um botão
4. O callback_query é disparado
5. O index.js identifica qual botão foi clicado (query.data)
6. A função correspondente do comando é executada
7. Resposta é enviada ao usuário

📌 EXEMPLO DE CALLBACK:

┌──────────────────────────────────────────────────────────┐
│ if (query.data === 'ping') await ping(bot, chatId);     │
└──────────────────────────────────────────────────────────┘

Quando um botão com callback_data='ping' é clicado, a função
ping() do arquivo comandos/ping.js é executada.


6️⃣ COMO CRIAR NOVOS COMANDOS
─────────────────────────────────────────────────────────────────────────────

🆕 PASSO 1: Crie um novo arquivo na pasta /comandos

Exemplo: comandos/meucomando.js

┌──────────────────────────────────────────────────────────┐
│ async function meucomando(bot, chatId) {                │
│     const mensagem = '✨ Olá! Este é meu comando!';     │
│     await bot.sendMessage(chatId, mensagem);             │
│ }                                                        │
│                                                          │
│ module.exports = { meucomando };                         │
└──────────────────────────────────────────────────────────┘

🆕 PASSO 2: Importe o comando no index.js

No topo do arquivo, adicione:
┌──────────────────────────────────────────────────────────┐
│ require('./comandos/meucomando')(bot);                   │
│ const { meucomando } = require('./comandos/meucomando'); │
└──────────────────────────────────────────────────────────┘

🆕 PASSO 3: Adicione o callback no index.js

Dentro de bot.on('callback_query', ...):
┌──────────────────────────────────────────────────────────┐
│ if (query.data === 'meucomando')                          │
│     await meucomando(bot, chatId);                        │
└──────────────────────────────────────────────────────────┘

🆕 PASSO 4: Crie um botão para seu comando (próxima seção!)

💡 EXEMPLO 1: Criar um Comando Simples (/saudacao)

Arquivo: comandos/saudacao.js

┌──────────────────────────────────────────────────────────┐
│ async function saudacao(bot, chatId) {                   │
│     const msg = '👋 Olá! Bem-vindo ao meu bot!';        │
│     await bot.sendMessage(chatId, msg);                  │
│ }                                                        │
│                                                          │
│ module.exports = { saudacao };                           │
└──────────────────────────────────────────────────────────┘

Adicionar no index.js:

┌──────────────────────────────────────────────────────────┐
│ // No topo:                                               │
│ require('./comandos/saudacao')(bot);                     │
│ const { saudacao } = require('./comandos/saudacao');     │
│                                                          │
│ // No callback_query:                                    │
│ if (query.data === 'saudacao')                            │
│     await saudacao(bot, chatId);                         │
└──────────────────────────────────────────────────────────┘

│ }                                                        │
│                                                          │
│ module.exports = { calcular };                           │
└──────────────────────────────────────────────────────────┘

9️⃣ DEPENDÊNCIAS
─────────────────────────────────────────────────────────────────────────────

A base usa os seguintes pacotes npm:

📦 node-telegram-bot-api (v0.66.0)
   └─ Biblioteca oficial para interagir com a API do Telegram
   └─ Usada para enviar mensagens, gerenciar callbacks, etc

📦 axios (v1.18.1)
   └─ Cliente HTTP para fazer requisições
   └─ Usado para fazer requisições a APIs externas

📦 yt-search (v2.13.1)
   └─ Busca vídeos no YouTube
   └─ Usada no comando /play para buscar músicas

📦 youtube-dl-exec (v3.1.9)
   └─ Download de vídeos/áudios do YouTube
   └─ Usada para fazer download das músicas

📦 fluent-ffmpeg (v2.1.3)
   └─ Manipulação de arquivos de áudio/vídeo
   └─ Converte arquivos para o formato desejado


🔟 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

❌ PROBLEMA: "Cannot find module"
✅ SOLUÇÃO: Execute npm install no terminal

❌ PROBLEMA: Bot não responde
✅ SOLUÇÃO: 
   • Verifique se o token está correto
   • Verifique a conexão com a internet
   • Reinicie o bot (Ctrl+C e node index.js novamente)

❌ PROBLEMA: "Undefined is not a function"
✅ SOLUÇÃO: 
   • Verifique se importou corretamente o arquivo
   • Verifique se exportou com module.exports
   • Procure por erros de digitação

❌ PROBLEMA: Callback não funciona
✅ SOLUÇÃO:
   • Verifique se o callback_data está igual no botão e no if
   • Verifique se as maiúsculas/minúsculas estão corretas
   • Procure erros no console (npm start mostrará erros)
