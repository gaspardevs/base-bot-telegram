📱 O QUE SÃO BOTÕES NO TELEGRAM?
─────────────────────────────────────────────────────────────────────────────

Botões são elementos interativos que aparecem em mensagens do Telegram.
Existem 2 tipos principais:

1. INLINE BUTTONS (Botões Inline)
   └─ Aparecem DENTRO da mensagem
   └─ Enviam dados para o bot processar
   └─ Mais comuns para interação

2. KEYBOARD BUTTONS (Teclado)
   └─ Aparecem como teclado abaixo do chat
   └─ Enviam mensagens de texto
   └─ Menos usados em bots simples


═════════════════════════════════════════════════════════════════════════════

🔘 TIPO 1: BOTÃO DE CALLBACK (Inline Button com Ação)
─────────────────────────────────────────────────────────────────────────────

Este é o tipo mais comum! Quando clicado, envia dados para o bot processar.

📐 ESTRUTURA BÁSICA:

┌─────────────────────────────────────────────────────────────────────────┐
│ {                                                                       │
│     text: '🔘 Texto do Botão',      ← O que o usuário vê              │
│     callback_data: 'acao_unica'     ← Identificador único              │
│ }                                                                       │
└─────────────────────────────────────────────────────────────────────────┘

💡 EXEMPLO COMPLETO:

┌─────────────────────────────────────────────────────────────────────────┐
│ const botoes = {                                                        │
│     reply_markup: {                                                     │
│         inline_keyboard: [                                             │
│             [                                                          │
│                 { text: '✅ Sim', callback_data: 'resposta_sim' },     │
│                 { text: '❌ Não', callback_data: 'resposta_nao' }      │
│             ]                                                          │
│         ]                                                              │
│     }                                                                  │
│ };                                                                      │
│                                                                         │
│ await bot.sendMessage(chatId, 'Você concorda?', botoes);              │
└─────────────────────────────────────────────────────────────────────────┘

🎨 COMO FICA NO TELEGRAM:

┌──────────────────────────────────────┐
│  Você concorda?                       │
│                                       │
│  [✅ Sim] [❌ Não]                    │
└──────────────────────────────────────┘

⚙️ PROCESSAR NO index.js:

┌─────────────────────────────────────────────────────────────────────────┐
│ if (query.data === 'resposta_sim') {                                    │
│     await bot.sendMessage(chatId, '✅ Obrigado por concordar!');        │
│ }                                                                        │
│                                                                         │
│ if (query.data === 'resposta_nao') {                                    │
│     await bot.sendMessage(chatId, '😢 Que pena! Tente novamente.');    │
│ }                                                                        │
└─────────────────────────────────────────────────────────────────────────┘

🌐 TIPO 2: BOTÃO DE URL (Abre um Link)
─────────────────────────────────────────────────────────────────────────────

Este tipo NÃO envia dados para o bot. Apenas abre um link.

📐 ESTRUTURA BÁSICA:

┌─────────────────────────────────────────────────────────────────────────┐
│ {                                                                       │
│     text: '🌐 Visitar Site',        ← O que o usuário vê              │
│     url: 'https://seu-site.com'     ← Link para abrir                  │
│ }                                                                       │
└─────────────────────────────────────────────────────────────────────────┘

💡 EXEMPLO COMPLETO:

┌─────────────────────────────────────────────────────────────────────────┐
│ const botoes = {                                                        │
│     reply_markup: {                                                     │
│         inline_keyboard: [                                             │
│             [                                                          │
│                 { text: '📲 WhatsApp', 
│                   url: 'https://whatsapp.com/channel/ID' }            │
│             ],                                                         │
│             [                                                          │
│                 { text: '🐙 GitHub', 
│                   url: 'https://github.com/seu-usuario' }             │
│             ],                                                         │
│             [                                                          │
│                 { text: '🌐 Site', 
│                   url: 'https://seu-site.com' }                       │
│             ]                                                          │
│         ]                                                              │
│     }                                                                  │
│ };                                                                      │
│                                                                         │
│ await bot.sendMessage(chatId, 'Visite nossos canais:', botoes);        │
└─────────────────────────────────────────────────────────────────────────┘

🎨 COMO FICA NO TELEGRAM:

┌──────────────────────────────────────┐
│  Visite nossos canais:               │
│                                       │
│  [📲 WhatsApp]                        │
│  [🐙 GitHub]                          │
│  [🌐 Site]                            │
└──────────────────────────────────────┘

📌 Quando clicado, abre o link automaticamente!

📦 TIPO 4: COMBINAR MÚLTIPLOS GRUPOS DE BOTÕES
─────────────────────────────────────────────────────────────────────────────

Frequentemente você quer reutilizar grupos de botões em vários comandos.

📂 Exemplo: arquivo botoes_menu.js

┌─────────────────────────────────────────────────────────────────────────┐
│ const botoesMenu = {                                                    │
│     reply_markup: {                                                     │
│         inline_keyboard: [                                             │
│             [                                                          │
│                 { text: '🎵 Música', callback_data: 'musica' },        │
│                 { text: '🎮 Jogo', callback_data: 'jogo' }             │
│             ],                                                         │
│             [                                                          │
│                 { text: '📊 Stats', callback_data: 'stats' }           │
│             ]                                                          │
│         ]                                                              │
│     }                                                                  │
│ };                                                                      │
│                                                                         │
│ module.exports = botoesMenu;                                            │
└─────────────────────────────────────────────────────────────────────────┘

📂 Exemplo: arquivo botoes_canais.js

┌─────────────────────────────────────────────────────────────────────────┐
│ const botoesCanais = {                                                  │
│     reply_markup: {                                                     │
│         inline_keyboard: [                                             │
│             [                                                          │
│                 { text: '📲 WhatsApp', 
│                   url: 'https://whatsapp.com/...' }                   │
│             ],                                                         │
│             [                                                          │
│                 { text: '📺 YouTube', 
│                   url: 'https://youtube.com/...' }                    │
│             ]                                                          │
│         ]                                                              │
│     }                                                                  │
│ };                                                                      │
│                                                                         │
│ module.exports = botoesCanais;                                          │
└─────────────────────────────────────────────────────────────────────────┘

📂 Como combinar em index.js:

┌─────────────────────────────────────────────────────────────────────────┐
│ const botoesMenu = require('./botoes_menu');                            │
│ const botoesCanais = require('./botoes_canais');                        │
│                                                                         │
│ const botoesCompletos = {                                               │
│     reply_markup: {                                                     │
│         inline_keyboard: [                                             │
│             ...botoesMenu.reply_markup.inline_keyboard,                │
│             ...botoesCanais.reply_markup.inline_keyboard               │
│         ]                                                              │
│     }                                                                  │
│ };                                                                      │
│                                                                         │
│ bot.sendMessage(chatId, 'Menu completo:', botoesCompletos);            │
└─────────────────────────────────────────────────────────────────────────┘

🎨 RESULTADO NO TELEGRAM:

┌──────────────────────────────────────┐
│  Menu completo:                       │
│                                       │
│  [🎵 Música] [🎮 Jogo]               │
│  [📊 Stats]                           │
│  [📲 WhatsApp]                        │
│  [📺 YouTube]                         │
└──────────────────────────────────────┘

🔧 BOAS PRÁTICAS
─────────────────────────────────────────────────────────────────────────────

✅ USE EMOJIS
   { text: '🎵 Tocar Música', callback_data: 'play' }

✅ DEIXE callback_data SIMPLES
   callback_data: 'play'        ← Bom
   callback_data: 'tocar_musica_do_usuario'  ← Evite muito comprido

✅ USE NOMES DESCRITIVOS
   callback_data: 'sim'        ← Bom
   callback_data: 's'          ← Evite abreviar muito

✅ MANTENHA CONSISTÊNCIA
   callback_data sempre em minúsculas
   callback_data sem espaços

✅ NÃO REPITA callback_data
   Cada callback_data deve ser único!
   
✅ ADICIONE BOTÕES DE VOLTAR
   Sempre ofereça um caminho para voltar ao menu anterior

❌ EVITE MUITOS BOTÕES
   Use máximo 3-4 botões por linha
   Não deixe o layout muito poluído

🚨 COMUM: EDITAR MENSAGEM COM BOTÃO
─────────────────────────────────────────────────────────────────────────────

Às vezes você quer EDITAR a mensagem anterior com novos botões:

┌─────────────────────────────────────────────────────────────────────────┐
│ // Criar botão Editar a mensagem anterior                              │
│ if (query.data === 'menu_principal') {                                  │
│     const novoBotao = {                                                 │
│         reply_markup: {                                                 │
│             inline_keyboard: [                                         │
│                 [                                                      │
│                     { text: '📂 Arquivo', callback_data: 'arquivo' },  │
│                     { text: '📝 Texto', callback_data: 'texto' }       │
│                 ]                                                      │
│             ]                                                          │
│         }                                                              │
│     };                                                                 │
│                                                                         │
│     await bot.editMessageText(                                          │
│         'Menu Secundário:',                                             │
│         {                                                              │
│             chat_id: chatId,                                           │
│             message_id: query.message.message_id,    ← ID da msg      │
│             reply_markup: novoBotao.reply_markup     ← Novos botões   │
│         }                                                              │
│     );                                                                 │
│ }                                                                       │
└─────────────────────────────────────────────────────────────────────────┘
